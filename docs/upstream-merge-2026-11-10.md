## 与原作者发布物的必要差异

1. 增加共享 `js/config.js`，从脚本 URL 推导项目根目录。
   修正原页面硬编码站点根路径的问题，资源、查询参数更新、配网返回和工具入口支持项目子目录。
   设备内嵌加载器也从其自身 URL 获取资源，避免再次加载原作者域名的旧入口。
2. 根页面和配网页保留当前 HTTP/HTTPS 地址及端口，不自动拼接 `:8080`。
   新 UI 移除 Apple 浏览器自动 HTTP 跳转，保留由用户点击的 HTTP 选择入口。
3. 新 UI 搜索与详情改用同一个可配置的 `/music` CORS 接口。
   本次检查原作者 `/api/music/search` 没有允许跨域的响应头，直接在独立域名请求它会失败。
   排行榜等同源接口由 `serve.py` 按固定路径转发，保留请求参数、请求体和上游状态码。
4. 新 UI 扫描移除对未定义 `isHttpsPage`、`encodeIpForPath` 的引用。
   默认直接 WebSocket；仅配置 `scanProxyBaseUrl` 时使用指定代理。
   取消扫描会停止定时任务、关闭连接并完成 Promise；ICE 探测只完成一次。
5. 独立 ADB 入口指向实际取得的 `adb/`，修正新 UI 原先不存在的 `adb.html` 链接。
   浏览器内 ADB 面板与 Android 专用独立控制台仍保留各自用途。
6. Service Worker 在页面 load 后注册一次并处理失败，避免原先重复嵌套 load 监听。
   本地浏览器确认注册成功；仍没有完整离线缓存，不声明可离线控制。
7. 统计默认关闭；`analyticsId` 可配置。保留本地 jQuery、vConsole 和 React 依赖，
   React 的 MIT 许可证保存在 `newui/js/vendor/LICENSE.react.txt`。

## 使用与验证

```sh
python3 serve.py
```

访问首页或 `newui/`。启动参数和静态部署方式见 [README](../README.md)。
`musicApiUrl` 可以指定自己的音乐服务；`serviceBaseUrl` 指定排行榜等接口的根 URL，
目录型配置地址应以 `/` 结尾。音乐转发是对公开 API 的依赖适配，没有恢复原作者的后端缓存或数据库。

12 项回归通过。执行的验证包括：

- 所有业务 JS、已有依赖 JS 和 HTML 内联脚本的语法检查。
- 浏览器回归：项目子目录、IP 校验、配网导航、EQ 保存/刷新/应用、队列协议与旧会话失效、
  旧/未确认设备版本禁用新队列、移动端面板、扫描取消、设备入口加载和 HTTPS/Apple 入口。
- 本地上游夹具验证 API 查询、POST 内容、未知路径拒绝转发及上游失败状态传播。
- 本地页面的实际跨域搜索：HTTP 200、`code=1`、10 条结果；
  本地排行榜转发返回 `success=true`、100 条结果；Service Worker 已注册。

浏览器自动化中使用的是合成设备状态和模拟 WebSocket，没有向真实音箱发送操作。
真实登录、音频投放、声道/延迟、DSP、配网、ADB、软件上传和安装仍需相应设备/宿主验证。
`1887`、`1888` 等设备能力依赖保持原协议边界；不能通过改网页版本号获得对应固件能力。
